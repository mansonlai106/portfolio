# Manson Portfolio

My personal portfolio website built with Next.js, TypeScript and Tailwind CSS.

## 🚀 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## 📦 Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the project.
